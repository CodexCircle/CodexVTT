Prima versione di **CodexVTT**: trascrizione voice-to-text locale con Whisper, senza account né telemetria.

## Novità

- **Nuovo nome** e nuova identità del progetto; l'interfaccia grafica verrà rifatta nelle prossime versioni.
- **Coda di trascrizione**: scegli più file insieme e vengono trascritti uno dopo l'altro; la coda vive nel core, quindi prosegue anche senza interfaccia aperta.
- **Aggiornamenti da GitHub**: «Controlla aggiornamenti» in Impostazioni, con controllo automatico all'avvio facoltativo (spento di default). Nessun dato personale lascia il PC.
- **Versione server**: la stessa interfaccia nel browser, in un container Docker o come servizio di Windows, con accesso protetto da token.

## Installazione

Scarica `CodexVTT-win-Setup.exe` da questa pagina. L'installer non è firmato: Windows SmartScreen può avvisare alla prima esecuzione («Maggiori informazioni» → «Esegui comunque»). Il controllo `SHA256SUMS.txt` conferma che il file è quello pubblicato.

## File della release

| File | A cosa serve |
|---|---|
| `CodexVTT-win-Setup.exe` | Installer |
| `CodexVTT-win-Portable.zip` | Versione senza installazione (senza aggiornamenti automatici) |
| `CodexVTT-0.1.0-full.nupkg`, `releases.win.json`, `RELEASES`, `assets.win.json` | Pacchetto e feed per gli aggiornamenti automatici: non eliminarli |
| `SHA256SUMS.txt` | Checksum per la verifica manuale |
