L'editor delle trascrizioni salva le correzioni e riproduce l'audio originale mentre correggi.

## Novità

- **Salva le correzioni**: nell'editor il pulsante *Salva* scrive nella cronologia il testo e i tempi di ogni segmento che hai corretto. Il riquadro delle proprietà è più essenziale.
- **Riascolto dell'audio originale**: se il file audio è ancora al suo posto, l'editor lo riproduce direttamente, anche saltando a un punto qualsiasi. L'audio non lascia mai il computer: viene letto dal file originale solo dall'app.

## Cose da sapere

- Se il file audio originale è stato spostato o cancellato, l'editor funziona come prima, senza riproduzione.
